# Dataset

No dataset is bundled yet. Before analysis begins, select a public transaction-level e-commerce dataset and record:

- Dataset name and original source URL
- License and permitted use
- Download date and version (if available)
- Date range, row count, and column definitions
- Known limitations, missingness, and any privacy considerations

Keep original files in `data/raw/` locally. Do not commit large datasets or any personal/customer-identifying information. Add only small, anonymized, reproducible samples when appropriate and permitted.

The project will not claim findings or model performance until the selected data has been inspected and the analysis has been run.
